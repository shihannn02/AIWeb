# 等频分箱边界提取（FIT → APPLY 模式）

## 问题

Train 和 Test 分箱的区间必须一致才能对比坏率稳定性。直接对 train 和 test 各自独立做 `pd.qcut` 会导致区间不同。

## 解决方案

### Fit 阶段（从 train 学边界）

```python
import pandas as pd
import numpy as np

x_train = ...  # Series
n = 10

# 对正常值（排除特殊值）做 qcut
qcut_result = pd.qcut(x_train, n, duplicates='drop')

# 从 IntervalIndex 提取边界
bin_intervals = qcut_result.cat.categories  # 注意：是 .cat.categories，不是 .categories

# 提取所有左右端点，去重排序
breaks = sorted(set(
    [interval.left for interval in bin_intervals] +
    [interval.right for interval in bin_intervals]
))

# 扩展为覆盖全范围的边界（第一项 -inf，最后一项 +inf）
bin_edges = [-np.inf] + breaks[1:] + [np.inf]
```

### Apply 阶段（用同一边界分 test）

```python
x_test = ...  # Series

# 用 train 的边界做 pd.cut
buckets = pd.cut(x_test, bins=bin_edges, right=True, include_lowest=True)
```

## 边界差异说明

| 维度 | Train | Test |
|------|-------|------|
| 第一箱左端点 | train 实际最小值（如 `0.516`） | `-inf`（扩展覆盖） |
| 其余箱边界 | 与 qcut 一致 | 与 train 完全一致 |
| `bin_label` 显示 | `(0.516, 0.652]` | `(-inf, 0.652]` |

第一箱左端从实际值扩展到 `-inf`，保证 test 上低于 train 最小值的样本落入第一箱而非 NaN。**这是预期行为，不影响对比。**
